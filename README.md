# HEX ISLE ～開拓の島～

ブラウザ（WebGL / three.js）で遊べる3Dの島開拓ボードゲーム。2〜4人でオンライン対戦できます。
サーバーは不要で、GitHub Pages にそのまま置けば動きます。

## 遊び方

- **部屋を作る**：部屋コード（5文字）と招待リンクが出るので、友だちに送る
- **参加する**：コードを入力するか、招待リンクを開く
- **1台で遊ぶ**：1つの画面で交代しながら遊ぶ（動作確認用）
- 操作：ドラッグで回転、右ドラッグで移動、ホイールでズーム。光っている場所をクリックすると置けます

## 入っているルール

初期配置（2巡目で資源をもらう）、資源の産出、建設（街道・開拓地・都市）、盗賊（7で手札8枚以上は半分捨てる）、
銀行交易（4:1）と港（3:1／2:1）、プレイヤー間の交渉、発展カード（騎士・勝利点・街道建設・収穫・独占）、
最長交易路、最大騎士力、10点で勝利。

## GitHub Pages で公開する手順

1. GitHub で新しいリポジトリを作る（例：`hex-isle`、Public）
2. このフォルダの中身をすべてアップロードする（`index.html` がリポジトリ直下に来るようにする）
   - ブラウザなら「Add file → Upload files」にフォルダの中身をドラッグ
3. リポジトリの **Settings → Pages** で、Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
4. 1〜2分後に `https://<ユーザー名>.github.io/hex-isle/` で遊べます

## 通信のしくみ

- WebRTC（PeerJS）による P2P。**部屋を作った人がホスト**になり、ルール判定をして全員に盤面を配信します
- 接続の仲介には PeerJS 公式の無料サーバー（0.peerjs.com）を使っています
- ホストがページを閉じるとゲームは止まります。同じブラウザで開き直すと「前回の部屋を再開」から続けられます（参加者は自動で同じ席に戻ります）
- 自前の PeerJS サーバーを使う場合は URL に `?peerhost=ホスト名&peerport=443&peerpath=/` を付けます
- 会社や学校のネットワークでは WebRTC が通らないことがあります

## ファイル構成

| ファイル | 内容 |
|---|---|
| `js/game.js` | ルールエンジン（描画・通信に依存しない） |
| `js/models.js` | 3Dモデル（タイルの木・羊・麦・山、家・都市・道・盗賊・港・ダイス）をコードで生成 |
| `js/render.js` | three.js のシーン、クリック判定、アニメーション |
| `js/net.js` | PeerJS によるホスト／クライアント通信 |
| `js/main.js` | 画面・HUD・入力 |
| `js/vendor/` | three.js r186 と PeerJS 1.5（同梱しているので CDN 不要） |

## 注意

- ホストのブラウザには全員の手札データがあります（気心の知れた仲間内で遊ぶ前提です）
- ゲームのルールを元にした非公式の作品です。商標を避けるため独自のタイトルにしています
